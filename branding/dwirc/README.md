# DWIRC vector brand source

This pack rebuilds the DarkWorld three-node identity as scalable artwork for the DWIRC Android app.

- `dwirc-app-icon.svg`: complete launcher icon artwork.
- `dwirc-adaptive-foreground.svg`: transparent Android adaptive foreground; use a near-black background layer.
- `dwirc-monochrome.svg`: single-colour Android themed-icon source.
- `dwirc-wordmark.svg`: horizontal DWIRC wordmark for About, website and promotional use.
- `png/`: rendered preview and production-size PNG files.

Brand colours: DarkWorld Red `#FF243D`, Graphite `#25272D`, Near Black `#090A0D`.

The adaptive foreground is drawn inside Android's safe region. Keep the three-node geometry unchanged when producing future variants.
